# Tic Tac Toe Arena

Tic Tac Toe Arena is a polished React + Vite game built for two players. It includes a modern scoreboard, winning highlight states, draw detection, reset controls, and responsive styling inspired by a modern portfolio-ready UI.

## Features

- Two-player local gameplay with turn tracking
- Win detection for all eight winning combinations
- Draw detection when the board is full
- Highlighting for winning cells
- Persistent score tracking for X, O, and draws
- Board reset and score reset actions
- Responsive layout optimized for mobile and desktop
- Custom color palette with green and pink accents

## Installation

1. Open a terminal in the project folder.
2. Run:

```bash
npm install
```

## Running the App

Start the local development server:

```bash
npm run dev
```

Then open the local URL printed in the terminal, usually:

```bash
http://localhost:5173
```

## How to Play

1. Player X goes first.
2. Click any empty square on the board.
3. Players alternate turns until someone wins or the board fills up.
4. Use New Game to start a fresh round.
5. Use Reset Scores to clear the score counters.
